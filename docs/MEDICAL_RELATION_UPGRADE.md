# 医学关系模型：同条件联合抽取对照

## 源码依据与适配边界

本轮阅读原作者 [GPLinker / duie_v1.py](https://github.com/bojone/GPLinker/blob/461fb1f5c9a828356daabd6d75d71a0cc1ff7f9a/duie_v1.py)。文件同时监督实体跨度、主体 / 客体起点链接及终点链接；解码取首尾链接关系标签的交集，按验证结果保存 checkpoint。上游使用硬编码数据 / 模型路径、12 层编码器、128 token 和未分医学类型的主体 / 客体头。本项目使用已有且经过单元验证的 PyTorch typed-span GPLinker 实现，实际在 CMeIE 上重新训练；不是直接复制上游参数，也不能称为上游模型完整复现。原作者按类别求和计算指针损失，本项目已有实现按类别均值，跨任务梯度比例不同；这次记录该差异，并保持试验代码冻结。

对照条件：同一个四层编码器、固定不重叠训练 / 验证 / 保留划分、53 类关系、384 token、seed42、六轮训练、有效 batch32、FP16、学习率 3e-5。现有基线先预测参与实体，再分类有类型约束的实体对；候选联合模型同时监督跨度与首尾链接。由于并行任务造成内存压力，候选使用微批次2 × 累积16，原基线使用4 × 累积8；有效批次和更新预算相同，但不能声称数值轨迹相同。原先未完成第一轮的尝试作为中止运行保留，不计入结果。比较的是完整架构，损失与关系表达均有差异，不能把差值归因于单个组件。

## 实验约束

验证集选择 checkpoint 与三组同条件阈值；先保存 selection，再开始复用保留集质量评测。沿用的加载器会提前将各划分读入内存，报告里的 test_opened_at 记录质量评测开始时间，而非首次物理读取标签；本实验不声称数据被密封或测试集从未见过。默认模型的发布条件提前声明：验证 F1 至少增加 0.5 个百分点，且旧保留集审计不下降。旧保留集只做发布否决，不能用来改阈值或选择另一候选；仍然不是独立未见最终测试。原训练代码、模型与报告全部保留。

尾链接消融只在同一 checkpoint 的推理解码中移除首尾关系交集约束，不代表重新训练的无尾损失模型。标点扰动将 ASCII 逗号、冒号、分号、括号替换为全角形式，字符数量与标签偏移保持不变；其分数衡量该种格式变化的敏感性，不能代表全部临床输入鲁棒性。

## 错误诊断

额外报告长文本（至少150字符）、共享实体与稀有关系（训练频次小于100）切片。稀有关系切片是包含至少一条稀有关系的整条文本，统计该文本全部关系，分组可重叠。漏检分为原标注位置的参与实体未检出与参与实体已检出但关系未检出；因重复提及对齐限制，该分区不是完整的因果错误归因。基线另用 gold 实体进行诊断，该分数不可作为部署成绩或真实推理表现。

实际分数及发布决定见下节。实验仍为单种子；按文档 bootstrap 不包含训练随机种子波动。疗效 / PICO / 不良事件记录仍没有独立训练模型与专家标注文献评测。

## 复现

在 README 的原医学数据与模型准备完成后运行 `python scripts/compare_medical_relations.py`。训练及比较写入独立的 `workspace/medical/relation-v2`，已完成报告拒绝覆盖。失败训练保留状态并要求先调查原因；不自动将失败运行当成完成。代码 / 数据 / 权重与选择报告保存指纹。公开仓库仅发布小型统计快照，原文语料、逐条预测错误和权重保留本机。

## 中断恢复

资源压力导致早期尝试中止，随后微批次1的进程在首次验证前意外退出，原因未确定，均未产生有效评测结果。最终协议使用微批次2、累积16，并增加每64次更新保存模型、优化器、学习率、FP16 scaler、随机状态及采样顺序的断点；验证固定微批次1。原始训练器保持不变，新增实现的差异独立记录。

断点恢复额外使用本地微型 CPU 编码器测试：分别在轮内第64次更新后、验证前人为中断，再恢复训练，最终权重、每轮历史和更新次数与连续训练一致。它只验证 CPU 训练恢复语义，不证明 CUDA 数值轨迹逐位一致，也不是医学质量成绩。

## 对齐损失的第二个预声明变体

第二个独立运行使用各指针任务按类别求和、再按样本求均值的原作者归约方式。模型、编码器、seed42、有效batch32、六轮、数据划分和三组阈值不变；已有均值对照完整保留。选择在新版质量评测前根据两个候选的验证分数封存，平分优先已完成对照；保留集只能否决发布，不能用来选择另一个模型。两个候选复用了验证集和旧保留集，bootstrap 未作多模型比较校正，因此仍需未来独立评测。

两组需要依次运行，不能共享同一张显卡同时训练。均值组完成后运行 `python scripts/compare_medical_gp_loss.py`；两组完成后运行 `python scripts/activate_medical_relation.py`，再运行 `python scripts/export_medical_relation.py` 验证并导出公开统计。训练中断后重跑对应比较入口会检查代码及数据指纹并恢复断点；已经完成的质量报告拒绝覆盖。若退出留下训练锁，应先核实锁中 PID 已退出，避免误删其他活跃任务的锁。

## 实际运行结果

- 基线：P 42.59% / R 33.72% / F1 **37.64%**，正确 2381、预测 5590、gold 7062。
- 联合：P 55.98% / R 19.41% / F1 **28.83%**，正确 1371、预测 2449、gold 7062。
- 配对差值 -8.81 个百分点；1,000 次文档 bootstrap 95% 区间 **[-10.19, -7.54]** 个百分点。此区间不包含训练种子波动。
- 验证集：基线 35.47% → 联合 29.74%；发布决定：**保留原两阶段模型**。
- 实际六轮训练，最佳 epoch 6，更新 2682，FP16 跳过更新 0，耗时 2263.5 秒，峰值 CUDA 分配 941.4 MiB。

尾链接推理消融 F1 **31.20%**。仅移除解码约束，权重和阈值不变。

标点变化后，基线 F1 **37.58%**，联合 **28.70%**。该扰动不能代表全部临床输入鲁棒性。

基线用 gold 实体诊断 F1 **69.52%**，不能计入部署成绩。

独立均值损失对照：验证 F1 **23.54%**，复用保留集 F1 **23.35%**。上面联合模型数字来自类别求和损失实验，两组均保留完整六轮历史。

基线漏关系中，原位置实体未检出 4233 条，参与实体已检出但链接漏检 448 条。

联合漏关系中，原位置实体未检出 3864 条，参与实体已检出但链接漏检 1827 条。

- 短文本：2125 条，基线 38.69% → 联合 30.80%。

- 长文本：253 条，基线 32.72% → 联合 19.28%。

- 共享实体：1431 条，基线 38.61% → 联合 29.08%。

- 含稀有关系文本：81 条，基线 22.04% → 联合 13.15%。

统计快照、预声明协议和六轮历史见 medical-results/relation_v3_report.json 或 relation_v2_report.json。原 v1 报告保留，NER 权重和 58.62% 结果不变。单种子稳定性、临床疗效抽取模型及专家验证仍待完成。
