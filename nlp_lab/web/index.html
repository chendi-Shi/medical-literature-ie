Transformers

AutoTokenizer、分类模型和 Trainer 提供统一训练接口，官方分类脚本支持数据加载和模型保存。

针对本项目的不足：示例默认使用 accuracy；数据去重、冲突审计及跨实验对照仍需项目层补齐。这个判断针对所读示例，非整个库。

Sentence Transformers

将训练器、损失函数和 evaluator 分离，适合句向量、检索和相似度任务。

针对本项目的取舍：分类任务先用编码器分类头；检索训练的损失与采样不能直接替代分类目标。

查看已核验代码 →

LlamaFactory

统一数据转换与处理，覆盖多种生成模型微调方法，适合指令与对话后训练。

针对本项目的取舍：首版是中文分类；先使用小编码器与分类指标，避免引入生成答案解析及额外推理成本。

已实现的流程

CSV / JSONL → 规范化与审计 → 固定数据版本 → CPU 基线或 Transformer 微调 → 验证集选模型 → 测试集评测 → 逐条错误与推理

“更好”指更适合首个可验证分类项目的工程方案。当前未证明算法性能超越上述框架。内置中文数据为人工编写的合成示例，只验证流程。

后续扩展
