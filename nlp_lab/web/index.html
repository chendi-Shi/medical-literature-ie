R-Drop

同一输入的两次独立 dropout 前向，以平均交叉熵加对称 KL 约束输出一致性。保留两个分布的梯度。

官方实现提供任务示例；组合效果依赖模型、数据和权重，需要在同预算、同种子的对照中验证。

官方仓库 → · 论文

FGM

按当前微批次损失的嵌入梯度生成一次 L2 扰动，再计算对抗交叉熵。计算完恢复原嵌入，避免累积梯度污染扰动方向。

与 R-Drop 形成 2×2 因子实验；不是原创算法声明，也不预先承诺二者组合一定最好。

本轮实现与边界

固定来源提交与文件指纹 → 数据重叠 / 重复 / 冲突审计 → 十类平衡训练预算 → TF-IDF Logistic / SVM → 小编码器四种训练目标 × 三种种子 → 验证选模 → 完整测试 → 温度校准、错误分析、扰动与配对区间。

单域新闻标题，2 epochs、3 种种子、10k 训练预算。结果只支持当前协议；公开语料可能进入预训练。合成扰动不能替代真实业务分布外评测。

原合成数据保留作流程自测。近重复检测、业务外部测试、断点恢复、多 GPU 和生产服务部署尚未实现。
